# Encryption–Decryption Web App

The Encryption–Decryption Web App is a lightweight full-stack application that demonstrates practical use of modern Java cryptography within a clean browser-based interface. The project combines a Spring Boot backend with a React (Chakra UI) frontend to provide a simple environment for generating keystores, creating keys, and performing AES, RSA, and DSA encryption/decryption.

On the backend, the system uses Java’s built-in security APIs to handle all cryptographic operations, including keystore management, key generation, and cipher execution. The frontend offers an accessible way to interact with these features, guiding the user through loading a keystore, selecting algorithms, and encrypting or decrypting text.
